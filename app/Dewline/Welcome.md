# Welcome to Dewline

When Claude Code, Codex or Cursor edits a note, Dewline marks the change, names the agent and lets you keep or revert it.

Keep clears the mark; Revert puts the old text back.

A marked change is already saved. Changes from git, a sync app or another editor are marked the same way. [Settings > Agents](dewline://setup-hooks) sets up the hooks that name each agent; without them, an agent’s edit shows as ANOTHER APP.

- Open a folder: ⌥⌘O
- Find a note: ⌘P
- New note: ⌘N
- Watch the demo again: Help > Replay the Demo

This note is Dewline’s own, kept outside your folders. Type anywhere. It saves as you go.
