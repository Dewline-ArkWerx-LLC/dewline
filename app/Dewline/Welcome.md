# Welcome to Dewline

Try it: [Show me a change](dewline://demo)

When Claude Code, Codex or Cursor edits a note, Dewline marks the change, names the agent, and lets you keep or revert it.

A marked change is already saved. Keep clears the mark; Revert puts the old text back.

Changes from git, a sync app or another editor are marked the same way. [Settings > Agents](dewline://setup-hooks) sets up the hooks that name each agent; without them, an agent’s edit shows as Another app.

- Open a folder: ⌥⌘O
- Find a note: ⇧⌘O
- New note: ⌘N

This note is Dewline’s own, kept outside your folders. Type anywhere. It saves as you go.
