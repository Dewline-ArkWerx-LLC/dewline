Everything in the app.

Dewline edits the Markdown files you already keep, and every feature on this page is built in. There are no plugins to find or update.

Download for Mac

macOS 26 or later. Free to start, with no account and no telemetry.

Other writers, marked by name.

When git, a sync app, a script or an agent changes a note while you’re typing in it, Dewline merges the change, keeps a version of the note first and marks the change with its writer: git, an agent named by its hooks, or Another app. Keep it with ⌘↩, revert it with ⌥⌘⌫, or step through them all.

How changes land

Agents sign their edits.

Hooks for Claude Code, Codex and Cursor tell Dewline which writes were theirs, checked by hash, so the change carries the agent’s name. Shell commands, Cursor Tab and some Cursor edits stay unnamed. Autosave waits while an agent writes. Agents can read what you kept and reverted with dewline changes.

Set up agent hooks

It knows the folder is a repo.

The sidebar shows git’s state for each file as one letter, and the folder header counts what changed since the last commit and how far the branch is ahead. A file deleted since then stays as a struck-through row. When a pull and your typing change the same paragraph, you pick which version stays, and no conflict markers enter the file.

How saving works

Markdown, drawn in the page.

Syntax hides until the caret reaches it. Tables, task lists, callouts and footnotes render in place. Math and Mermaid diagrams are drawn natively, with no JavaScript, and code blocks highlight 50 languages, with a Copy button.

What Dewline reads

Find it by name, text or link.

Quick Open (⌘P) jumps to a note or a heading. Find in Files takes regular expressions, a path: filter and Replace All. Type [[ to link a note, read its backlinks beside it, and rename it without breaking a link.

Find and replace

Ten formats out.

Export a note as PDF, Word, HTML, Rich Text, OpenDocument, EPUB, LaTeX, portable Markdown, plain text or a PNG. Export reads what the window shows and never changes the Markdown file. In Finder, Quick Look previews any .md file.

What each format keeps

A command line, MCP and links.

The app comes with a dewline command. Make it your $EDITOR, open a file at a line, export from a script, capture to your inbox, or serve a folder to an agent over MCP. A dewline:// link opens a note at a line from any app.

The command line

And the rest

Smaller things, each one in the app today. The docs cover every one, and Keyboard lists every shortcut.

Writing

Live or Source
Syntax hides until the caret reaches it. View > Show Source (⌥⌘U) shows every character, with line numbers.
Tables
Tab moves between cells and adds a row at the end. Format > Insert Row and Insert Column.
Paste and copy
Pasting from a web page or Mail gives Markdown. Copy as Markdown or as HTML.
Images
Paste or drop an image and it is saved beside the note, with its original bytes.
Vim mode
Motions, operators, text objects, registers and :w.
Focus and typewriter
Dim every block but the caret’s, or keep its line in the middle.
Spelling and word count
Spelling and Writing Tools skip code, math and links. The word count sits in the status bar.
Code files
Turn on Open code files and source files open as code, highlighted, with line numbers.

Files and saving

Saves itself
Closing a tab, quitting, sleeping or switching apps saves. There is no save sheet.
Only what you changed
A save writes the bytes you edited and never overwrites a newer copy.
Drafts
When a save is refused, the status bar says why and keeps a draft you can restore.
Earlier versions
File > Earlier Versions lists each one with its time and writer. A restore is one undo.
Writes while closed
A change made while the note was closed, or Dewline was quit, is marked when you open it.
Quick Look
Press Space on a .md file in Finder to see it rendered in your theme.

Finding your way

Quick Open
⌘P, with @ for headings, : for a line and # for headings across the folder.
Command palette
⇧⌘P runs any menu command and switches theme, mode and Vim.
Outline
View > Sidebar Outline swaps the tree for the note’s headings.
Backlinks
The notes that link to this one, beside it. Each opens at its link.
Tags
⌘-click a #tag to search the folder for it.
Agent folders
.claude, .cursor and .github show in the tree, Quick Open and Find in Files.
Pick up where you were
Open Recent lists folders and notes. Windows, tabs and the caret come back after a quit.

Agents

Hook setup
Settings > Agents or dewline doctor --install-hooks, with a backup of each file it changes.
Autosave waits
While an agent’s edit is open, autosave and outside changes wait, up to 10 seconds.
Shell commands
A change that lands during a Claude Code shell command says so on its stamp.
Revert after typing
Revert still works after you type around a change. When it can’t, the stamp says why.
Decisions
dewline changes and the MCP decisions tool show agents what you kept and reverted, without the text.
No model inside
Dewline ships no model and needs no account. Bring the agent you use.

Looks

Four themes
Tidewater and Onionskin for light, Nightwatch and Carbon for dark, or follow the system.
Your fonts
Any font on your Mac for body, headings and code.
Text
Text size, line height and line width. ⌘+ and ⌘- zoom every window.
Scroller rail
Marks for headings and for changes waiting on you.
Link previews
A link alone on its line shows a card. Off until you turn it on.

Privacy and build

No account
No sign-in, analytics or crash reporter. Dewline goes online for updates and, if you turn them on, link previews.
Native
AppKit and TextKit 2 over a Rust engine. No Electron, and no JavaScript runs on your notes.
CommonMark
The parser passes all 652 examples of the CommonMark 0.31.2 spec.
Updates
Signed and notarized, for Apple Silicon and Intel. It updates itself.

Open a folder.

The first launch runs a short guide: a demo agent edits Welcome.md, and you revert one change and keep the other. Then open the folder your agent works in.
